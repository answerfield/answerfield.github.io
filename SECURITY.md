# Sicherheit

Bitte melde Sicherheitslücken nicht als öffentliches Issue.

Nutze auf GitHub „Private vulnerability reporting“ (Reiter „Security“, dann „Report a vulnerability“) oder schreibe an kontakt@indibit.eu.

Wir bestätigen den Eingang zeitnah und melden uns, sobald wir die Meldung geprüft haben.
