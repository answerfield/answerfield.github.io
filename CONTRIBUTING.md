# Mitwirken

Issues und Pull Requests sind willkommen.

## Bauen und testen

Voraussetzung ist Node.js 22.12 oder neuer.

```sh
npm ci
npm run build
npm test
```

## Developer Certificate of Origin

Jeder Commit braucht ein `Signed-off-by`, damit wir ihn annehmen dürfen. Das fügt Git mit `-s` hinzu:

```sh
git commit -s -m "Beschreibung der Änderung"
```

Damit bestätigst du das Developer Certificate of Origin 1.1, dessen Wortlaut in der Datei [DCO](DCO) steht.

## Lizenz

Beiträge stehen unter der Lizenz der Datei, die sie ändern; welche das ist, steht in `REUSE.toml`.
